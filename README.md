QR Code Component

A responsive QR code landing page built as part of a Frontend Mentor challenge. This project focuses on clean layout, proper spacing, and responsive design using only HTML and CSS.

![QR code Landing page preview](preview.png)

The challenge

Users should be able to:

- View the page clearly and as responsive as it could be.
- Notice that is actually a landing page for QR code.
     My process : 
- Built with
Semantic HTML5 markup
CSS
Flexbox
Mobile-first workflow

    What I learned

This challenge was a great introduction to structuring a simple, centered UI component with proper HTML semantics and CSS best practices. Key takeaways included:

- Using Flexbox to center content both horizontally and vertically, rather than relying on manual positioning.
- Applying box-sizing: border-box so padding and borders don't unexpectedly affect element sizing
- Keeping styles predictable and maintainable by avoiding unnecessary properties on elements that don't need them
